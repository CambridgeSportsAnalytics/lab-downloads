Getting started

  1. Install

    Open CSA-Prediction-Lab.dmg and drag Lab into your Applications folder.

  2. Open it the first time

    This early build is not yet notarized by Apple, so macOS will stop it the first time. Open Lab once, then go to System Settings → Privacy & Security, scroll down and click Open Anyway.

    You only need to do this once.

  3. Activate

    Lab shows a request code tied to your Mac. Email it to prediction@csanalytics.io, then paste the licence token you receive back into Lab.
